# Restaurant Menu - React Next.js

A responsive, single-page restaurant menu application built with React and Next.js, featuring categorized menu items with filtering capabilities.

## 🚀 Live Demo

[View Live Site](https://stjeanzebdine.vercel.app/)

## 📋 Features

- **Single Page Application**: All menu categories displayed on one convenient page
- **5 Menu Categories**:
  - 🥙 Saj
  - 🥤 Drinks
  - 🥪 Sandwiches/Mezza
  - 🫖 Arguileh
  - 🛒 Dikkan
- **Category Filtering**: Each category has specific filtering options for easy navigation
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Fast Performance**: Built with Next.js for optimal loading speeds
- **Modern UI**: Clean and intuitive user interface

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Frontend**: [React](https://reactjs.org/)
- **Styling**: CSS/SCSS _(or specify your styling solution)_

## 🚦 Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/restaurant-menu.git
cd restaurant-menu
```

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Run the development server:

```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🎯 Menu Categories

### Saj 🥙

Traditional Lebanese flatbread with various fillings and toppings.

### Drinks 🥤

Refreshing beverages including traditional and modern options.

### Sandwiches/Mezza 🥪

Delicious sandwiches and mezze platters for sharing.

### Arguileh 🫖

Traditional hookah/shisha options with various flavors.

### Dikkan 🛒

Special items and additional products.

## 🔍 Filtering System

Each category includes intelligent filtering options:

- Filter by ingredients
- Filter by dietary preferences
- Price range filtering
- Popularity sorting
